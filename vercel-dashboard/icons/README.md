Place generated PWA icons in this folder.

Suggested workflow:
- Use https://realfavicongenerator.net/ (or similar)
- Upload the dashboard logo
- Generate the PNG sizes referenced by `vercel-dashboard/manifest.json`
- Put them here with the exact filenames:
  - `icon-72x72.png`
  - `icon-96x96.png`
  - `icon-128x128.png`
  - `icon-144x144.png`
  - `icon-152x152.png`
  - `icon-192x192.png`
  - `icon-384x384.png`
  - `icon-512x512.png`
